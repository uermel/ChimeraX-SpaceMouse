# Changelog

## [0.1.0](https://github.com/uermel/chimerax-spacemouse/releases/tag/ChimeraX-SpaceMouse%20v0.1.0) (Unreleased)

### Features

- Initial release
- 6DoF SpaceMouse support for ChimeraX
- View mode: pan, zoom, and full 3-axis rotation
- Model mode: translate and rotate selected models
- Configurable sensitivity for translation, rotation, and zoom
- Axis inversion for all 6 axes (x, y, z, roll, pitch, yaw)
- Custom button-to-command bindings
- Settings dialog with full configuration options
- Support for orthographic, perspective, VR/XR, and LookingGlass cameras
